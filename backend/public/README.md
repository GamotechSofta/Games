# Downloadable files

Place your APK (e.g. `myapp.apk`) in this folder. It will be served at:

- **Local:** `http://localhost:3010/downloads/myapp.apk`
- **Production:** `https://your-backend-url/downloads/myapp.apk`

The frontend Download page links to `/downloads/myapp.apk` (same origin as the API).
